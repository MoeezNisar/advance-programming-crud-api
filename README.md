# Advance Programming CRUD API (Express.js, Modular MVC)

Data ek array mein memory mein store hota hai (database nahi), server restart par reset ho jata hai.

## Setup
1. `npm install`
2. `npm start`  -> http://localhost:3000

## Endpoints
- POST /api/auth/register, POST /api/auth/login
- GET/POST /api/categories, GET/PUT/DELETE /api/categories/:id
- GET/POST /api/courses, GET/PUT/DELETE /api/courses/:id
